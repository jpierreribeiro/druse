# Why the LOCAL gate run in raw/gate.txt stops at WP72

It is the container, not the change, and this file is the proof rather than
the claim.

3,000-connection laboratory and fails closed when it cannot. This container's
HARD limit is 4096, so no user in it can satisfy that precondition:

  ulimit -Sn = 1024
  ulimit -Hn = 4096

same user, no changes from this work package present:

Identical failure, identical line. The gate reached and PASSED the R2-WP03
controls before this point — see raw/gate.txt lines 1513-1527, seven mutants
red for their own reasons.

CI IS THE AUTHORITY (.github/workflows/gate.yml). This local run is a
diagnostic, and G4 says so: a gate run on a shared container answers
deterministic-correctness questions and not capacity ones.
